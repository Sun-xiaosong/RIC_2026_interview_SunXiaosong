# RIC 选课指南

基于 RIC 课程平台 Starter 开发的选课决策辅助工具:搜索找课 → 查看成绩分布与课程特征 → 地图确认上课位置 → 班次表安排时间 → 浏览评价 → 收藏备选,覆盖选课前调研的完整流程。

```text
ric-course-starter/
├── frontend/   React + TypeScript + Vite + Ant Design(含 Leaflet 地图)
└── backend/    Go 标准库 HTTP API + SQLite
```

## 环境要求

- Node.js 20 或以上、pnpm 10
- Go 1.21 或以上

## 运行方式

启动后端(第一个终端):

```bash
cd backend
go run .
```

> 注意:后端已拆分为 `main.go` / `handlers.go` / `models.go` 三个文件,请使用 `go run .`(而非 `go run main.go`,后者只编译单个文件会报未定义错误)。
> 首次启动自动从 `data/ric_course_sample_dataset.json` 建立 SQLite 数据库;`go run . --init-db` 可清空重建。

启动前端(第二个终端):

```bash
cd frontend
pnpm install   # 仅首次
pnpm dev
```

访问 <http://localhost:5173>。前端的 `/api` 请求由 Vite 代理转发到 `127.0.0.1:3001`,无需额外配置;地图底图(OpenStreetMap)需联网加载。

## 实现的功能

### 1. 课程详情(题目必做项)

- 点击课程进入详情页(URL 形如 `/courses/COMP3314`,可分享、支持浏览器前进后退)
- 课程信息:前置要求、课程简介、开课院系
- **成绩分布**:14 档成绩(A+ ~ F、P/F)纯 CSS 柱状图,悬停显示人数与占比
- **课程特征**:导修课/论文/期末考试/课堂展示/课程项目/是否点名的学生投票双段条
- **班次时间表**:按学期分组,Section、教师、每周上课时间(周几 + 时段 + 教室 + 日期段)
- **评价浏览**:最新/最热排序,服务端分页(每页 5 条)

### 2. 课程搜索(后端 API 实现)

- 输入即搜(300ms 防抖),同时匹配课程名称与课程代码
- 匹配语义:标题按**词首**匹配(标题中某个单词以关键词开头)、代码按**前缀**匹配;单字符关键词仅匹配代码前缀,避免单词中段字母造成噪音;**纯数字**关键词可匹配代码中任意位置(如搜 `3314` 找到 COMP3314)
- 排序规则:**名称完全匹配 > 代码完全匹配 > 名称词首匹配 > 代码前缀匹配**,同级按代码排序
- 可叠加院系下拉筛选(选项及课程数来自 `/api/departments`)
- 匹配与排序在 Go 内存中完成,规避 SQL `LIKE` 的 `%`/`_` 转义问题,大小写不敏感

### 3. 课程地图

- 详情页将全部课次地点标注在港大地图(Leaflet + OpenStreetMap),支持滚轮缩放与拖动
- 地点按教学楼聚合:一栋楼一个标记,标记上显示楼栋缩写与课次数,弹窗列出具体课次
- 数据集 21 个教室归入 9 栋楼(Main Building、K.K. Leung、Meng Wah、图书馆新翼、张玉明物理楼、Knowles、徐展堂、综合楼、百周年校园);楼栋坐标取自 OpenStreetMap 建筑数据,与地图底图精确对齐
- 未标注地点的课次(venue 为空)在地图下方注明数量

### 4. 课程收藏

- 课程列表每行带爱心图标,无需进入详情页即可一键收藏/取消
- 详情页收藏按钮;数据存于浏览器 localStorage(无需登录)
- 点击右上角头像 → 我的收藏,集中查看已收藏课程
- 跨页面实时同步(React Context),跨标签页同步(storage 事件),刷新不丢失

### 5. UI 优化

- 主题定制(学术蓝主色、圆角、浅灰底)与顶部导航布局(课程浏览/我的收藏/头像菜单)
- 课程列表以"好评率"(百分比 + 迷你进度条 + 投票数)替代裸点赞/点踩,提升信息密度
- 详情页两栏布局(主内容 + 概要/地图侧栏),窄屏自动折叠为单栏
- 窄屏(<768px)列表切换为卡片形态;加载骨架屏、空态、404/错误页齐备
- 成绩分布图、特征投票为纯 CSS 实现,未引入图表库;地图组件按需懒加载拆包

## 后端 API 一览

| 端点 | 说明 |
|---|---|
| `GET /api/health` | 服务与数据库状态 |
| `GET /api/courses?q=&dept=` | 课程列表/搜索/院系筛选(`q`、`dept` 可选) |
| `GET /api/departments` | 院系列表及课程数 |
| `GET /api/courses/{code}` | 课程详情(成绩分布、特征投票、班次,不含评价) |
| `GET /api/courses/{code}/reviews?page=&pageSize=&sort=` | 评价分页,`sort=latest`(默认,按时间)或 `hot`(按点赞净数) |

错误约定:课程不存在返回 404、非法 `sort` 返回 400、非 GET 返回 405,响应体均为 `{"error": "..."}`。

## 产品思路

选课决策的核心是"这门课值不值得上、时间地点合不合适":

1. **找课**:搜索排序让精确目标(知道课名)和模糊探索(只记得关键词)都快;
2. **值不值得**:好评率一眼可判,成绩分布反映给分情况,课程特征投票回答"有没有期末/论文/点名"这类高频问题,评价按最热排序先看高赞经验;
3. **合不合适**:班次表看时间,地图看上课楼栋位置——两栋楼相距多远步行多久,是港大选课的实际痛点;
4. **备选管理**:收藏把候选课集中对比,最后统一取舍。

## 已知限制

- 数据集为抽样:全库 184 条评价、10 门课;`courses.reviewed_count` 为平台全量口径(与抽样评价数不一致),因此展示一律采用评价表真实条数
- `description` 字段在数据集中全部为空,详情页显示"暂无简介"
- 部分院系名称在数据源中被截断(如 "School of Computing and Data S"),原样展示
- 无登录系统,收藏仅存于本浏览器
- 地图楼栋坐标来自 OpenStreetMap 建筑数据;百周年校园(CPD)标记为两塔间中央平台的近似中心点
